gpt-6.1-terra(Codex)는 범위가 정해진 UI 수정과 자막 스타일 수정을 안정적으로 끝내고, 교차 코드 리뷰에서 경계 버그를 실제로 찾는다.
결과 파일·인코딩이 흐트러질 수 있으니 BOM 금지와 결과 확인을 지시·운영에 넣는다. 발화 경계처럼 근거 측정이 필요한 일은 추정으로 남길 수 있어 별도 완료 조건으로 적는다.

## 잘하는 일
- 페널티 표기, 입구 창 축소, 지도 포커스, 스크롤 칸 등 범위가 정해진 UI 수정
- 인자를 추가해 남의 데이터에 값이 새지 않게 경계를 챙긴다
- 전체 테스트 실패를 숨기지 않고 보고한다
- 교차 코드 리뷰에서 드래그 중 창 닫기·초기화 순서 같은 경계 버그를 실제로 찾아 테스트까지 붙인다
- 자막 스타일 수정(medium): 큰 굵은 글씨·한 줄 구성을 하고 실제 렌더 폭·프레임/PTS·오디오 동일성·축소 프리뷰를 납품했다
- 못 채운 완료 조건을 솔직하게 밝혀 후속 검증으로 넘길 수 있었다

## 약한 일
- RESULT.md를 안 남기거나 STATE.md 한글이 깨진 적이 있다
- 새 파일에 BOM·CRLF가 섞인다
- 자막 새 분절 10곳을 실제 쉼·단어 시각 대신 글자 수 비례로 추정해 "의미·발화에 맞추라"는 완료 조건을 못 채웠다. 교차검증에서 문구 위치와 0.6~1초 선행 표시가 고쳐졌다(한 작업 관찰)

## 지시에 넣을 문구
- 파일·줄·금지 범위를 적고 "BOM 금지"를 명시한다
- 결과는 council_member diff로 의장이 직접 확인하고, 독립 리뷰는 의장이 맡는다
- 자막: 스타일 수정과 새 싱크 경계 검증을 별도 완료 조건으로 적고, 경계마다 실제 음성 쉼·단어 시각 근거와 신뢰도를 요구한다. 글자 수 비례만으로 완료 판정하지 않는다. 정밀 정렬은 별도 검증 위원에게 맡길 수 있다
