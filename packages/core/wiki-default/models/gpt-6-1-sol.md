Codex image_gen으로 그림을 생성하고 코드에 연결하는 일, 재현 기반 버그 조사, 계약을 준 병렬 연결, 끊긴 작업 인수, 감사 기록에서 규칙 문서를 정리하는 일, 사실을 CLI로 먼저 확인하고 여러 파일 설정을 한 번에 바꾸는 일, 원본 보존을 증명하는 미디어 후처리, 생성 영상 소품 칠하기를 엄격한 수치 QC로 판정하는 일, 수천 개 파일 이동과 경로 재작성·검증 원장에 강하다.
금지 파일과 인터페이스 계약을 명시하면 Claude 한도가 찼을 때 대체 인력으로 맞는다. advisor와 explore 도구가 council에서 붙는다(전에는 없어서 코드를 직접 읽었다): 계획 확정 전·같은 오류 2회·완료 선언 전에 consult로 상담하고, 저장소 탐색은 explore에 맡기라고 지시에 적는다. 인물 포함 이미지 편집은 인물 유사성을 따로 대조해야 한다.

## 잘하는 일
### 그림 생성+코드 연결 (high)
- 배경 27장을 결을 맞춰 생성하고 프롬프트 기록·경로 표·코드 연결·테스트·캡처·다른 GPT 교차 리뷰까지 혼자 한다. 실측 창 크기(PC 1050·1400, 모바일 390)로 캡처하고, 캔버스 그리기를 공용 함수로 재사용한다
- 16×16/20×20 픽셀 아이콘을 기존 세트의 크기·색 수·외곽선에 맞춰 정규화하고 비교 시트를 만든다. 지시와 다른 실제 경로(공유 아틀라스)를 찾아 전용 아이콘으로 분리하고 32px 8종을 한 번에 만든다. 공용 배치 로직도 단위 테스트와 함께 깔끔하다
- ComfyUI 영상 반복 수정: image_gen 키프레임+API 그래프 메모리 패치+제출·폴링·mux·검수를 한 번에 한다(1회 40~80분). 0.1초 간격 시트와 원화|이전|새판 비교를 스스로 만들고, 미달은 "부분 성공"으로 정직하게 보고한다
- 자기 prompt_id만 /interrupt하는 등 큐 조작이 안전하다. 인계받은 작업도 잘 잇는다
- image_gen 안전필터 거절은 "성인·완전 착의"로 다시 요청해 스스로 푼다
- 그림을 코드로 만드는 작업(로고 엠블럼 분리·재생성 스크립트·비교 시트·해시/알파 검증)의 구조를 잘 만든다(단, 아래 "육안 통과" 기준 주의)
- 참조 이미지 편집(medium): 참조 경로·정확한 문구·작은 프리뷰·버전별 저장을 주면 실제 생성·수정과 기록을 한다. 생성 도구의 미세 픽셀 변화·출력 해상도 차이도 밝힌다

### 미디어 후처리·불변성 검증 (자막 합성 high, 프레임 교체 medium)
- 원본 보존을 숫자로 증명한다: 프레임 PTS, AAC/PCM 해시, 전체 디코드, 교체 밖 프레임 PSNR inf, 텍스트 매핑과 재현 기록을 구체적으로 납품했다
- 생성 영상 프레임 교체(가이드 프레임 손 제거+짧은 샷 재생성+마스터 교체): 위키의 드래프트 우선 규칙을 지켜 저해상도 후보를 먼저 내고 승인 뒤에만 최종 품질을 생성했다. 60프레임 전부 손·소품 접촉표로 확인하고, 버전별 하위 폴더로 산출물을 격리했다
- 한계를 정직하게 적는다(드래프트를 업스케일했다, 생성형 편집이라 얼굴 미세 차이가 있을 수 있다, 청취는 안 했다)
- 지시에 적힌 선행 RESULT.md 경로가 없으면 통합 브랜치 파일과 공유 폴더 json으로 스스로 보충한다. 패킷의 폴더 경로가 틀리면 실제 경로를 찾아 쓰고 기록한다

### 생성 영상 소품 칠하기·합성과 EL 후보 (수치 QC)
- Codex 내장 이미지 생성 + 추적 합성으로 소품을 칠하거나 지운다(삽 조각·벨트·손잡이 제거). 흡수 이후 전체 프레임을 감사한다
- 품질 기준에 못 미치면 "승인 교체본 없음"으로 거절하고 재생성을 제안한다(방패·벨트). 억지로 넣지 않는다
- ElevenLabs 후보를 여러 개 만들고 받아쓰기 일치·입 길이 표를 함께 낸다. 조사 문서도 꼼꼼하다

### 대량 파일 이동·경로 재작성·검증 원장 (high)
- 수천 개 미디어 재정리(이동·.kdenlive 경로 보정·스크립트 출력 경로 수정·중복 삭제)를 두 번 맡겨 둘 다 재배정 없이 끝냈다(1회 각 60~70 호출, 15~25분)
- 지시하지 않은 안전장치까지 스스로 만든다: undo 충돌 검사, XML 원본 원장, 읽기 fallback helper, 전체 해시 검증, 공유 사본·정본 바이트 일치

### 재현·조사·계약 기반 연결
- 재현 못 하면 코드를 고치지 않고 "재현 안 됨, 회귀 테스트만"이라고 보고한다. 사용자 가설을 넣어 재배정하면 실제 원인을 찾아 전후를 계측한다. 역사 추적으로 원인을 좁힌다
- 밸런스 기준을 못 맞추면 금지 배율을 건드리지 않고 한계를 보고한다. 결정적 난수·지문 동일까지 챙기고, 리뷰 서브에이전트(작성자 외 리뷰)를 스스로 돌린다
- 병목 측정(A/B 정역순), 문구·코드 전수 대조와 회귀 테스트, 7개 언어 통합, 충돌 해결 핸드오버, 승인 범위만 지우는 대량 정리(빌드 크기 전후 측정), 근거가 촘촘한 레거시 조사 보고서
- 폼 필드·값·응답 형태를 계약으로 적어 주면 백엔드가 완성되기 전에 세 탭 연결을 목업으로 끝내고, 합칠 때 충돌이 없다(27 calls)
- 끊긴 Claude 위원 작업을 새 worktree(또는 같은 worktree)에서 이어받아 STATE.md·로그로 생성 완료를 확인하고, 재생성 없이 분석·보고를 마친다. 앞 위원의 눈 판정을 믿지 않고 전부 다시 확인해 지표 함정(배경 번쩍임)을 찾았다. 허용 경로·금지 사항을 정확히 지킨다
- 인계 재개 때 지시에 없던 꼼꼼한 시간·메모리 측정표를 만들고, 결론의 한계(예: RAM 효과를 분리할 수 없음)도 정직하게 적었다

### 여러 파일 설정 변경: CLI로 사실 먼저 확인 (medium)
- 모델 사다리 확장에서 "1단계로 CLI에서 실제 이름 확인 → 확인 안 되면 보수적 가정" 지시를 그대로 지켜 `agy models`로 사실을 먼저 확정하고 RESULT에 명령·출력을 남겼다([Antigravity CLI(agy)](common/ai-agents/antigravity-agy-cli))
- 13개 파일(코어·드라이버·서버 API·웹 UI·README·테스트)을 한 번에 일관되게 고쳤다
- 지시에 없던 빈틈(모델 접미사로 추론 한도를 우회하는 경우, 핸드오버 때 상속 추론 수준이 새 모델 상한을 넘는 경우, 서버 /api/models)까지 찾아 테스트로 막고, Playwright로 UI 캡처까지 남겼다
- lockfile이 깨져 `npm ci`가 실패하자 `npm install --package-lock=false`로 우회하고 lockfile은 건드리지 않았다

### 감사 기록에서 규칙 문서 정리 (high)
- 여러 감사·재그림 기록에서 그림 스킬용 교훈 18규칙을 지정 형식으로 빠르게 썼다(30 calls, 약 10분). 출처 21경로 존재 확인·두 사본 byte 일치·`git diff --check`까지 스스로 검증하고, 읽기 전용 서브에이전트로 근거를 교차 확인했다
- 옛 감사의 지시가 이후 사용자 결정으로 대체된 것을 구별해 "옛 값 복사 금지"로 적는다
- 범위를 지킨다: 다른 위원 담당 파일은 링크만 걸고 만들지 않으며, 그 링크가 머지 전까지 빈다는 점도 보고한다. 문서만 바꾼 작업이라 테스트를 안 돌렸다는 사실도 밝힌다

## 약한 일
### 해석
- 모호한 부분을 가장 단순하게 해석한다(모든 경로를 같은 ㄹ자로). '필요하면'이라고 쓰면 image_gen 대신 SVG로 만든다
- 앞 지시와 뒤 금지가 충돌하면 뒤를 따른다
- "결이 안 맞으면 보고"를 받으면 만든 것을 전부 복원하고 끝낸다(시안이 사라진다)
- 노출 관련 지시는 보수적으로 줄여 해석한다
- '보류' 규칙을 넓게 해석한다: 디렉터리 mtime까지 최근 수정으로 보고 801개를 보류했고, 보류 프로젝트가 참조하는 재료도 보호했다. 위험 작업에는 장점이지만 진도가 덜 나간다
- 대상 함수의 상한을 안 보고 효과 없는 수정을 "완료"로 보고한 적이 있다(sonnet과 같음)

### 그림·합성
- 결과가 "너무 GPT스럽다"고 거절된 적이 있다(기준 그림을 주면 형상은 따른다)
- 여러 인물 앙상블 그림에서 한 인물이 사용자에게 어색하다는 지적을 받았다. 실제 영상 컷+설정화+이전판을 붙인 국소 편집으로 고쳐졌다 → 인물 유사성은 따로 대조한다
- 리소스 용량(장당 0.5~0.8MB)에 무신경하다
- 자체 "육안 통과" 기준이 관대해 글자 크기·색이 원본과 달라도 완료로 보고한다
- 첫 소품 칠하기에서 넓은 영역을 호모그래피 한 장+평활로 추적해 소품이 미끄러졌다([claude opus](models/claude-opus)가 조각별 KLT affine으로 다시 합성해 고쳤다)

### 환경·보고
- 비어 있던 공용 포트에 서버를 띄우고 남긴다
- "Selected model is at capacity"로 멈출 수 있다(같은 provider 계정이면 핸드오버 불가)
- 내부 Gemini CLI 호출이 UNSUPPORTED_CLIENT로 반복 실패한다(결과와는 무관)
- 전체 테스트가 길면 중단하고 미완료로 보고한다(병렬 시간초과면 `--maxWorkers=2`)
- 테스트를 위원 worktree 기준으로만 돌린다. 통합 worktree에서는 메인의 낡은 패키지 때문에 서버 smoke가 실패한 적이 있다(환경 문제)
- RESULT.md가 길고 방어적이며 기호가 많아 의장이 요점을 다시 뽑아야 한다. RESULT summary 칸이 비고 요약이 본문 끝에만 있는 경우가 있었다
- 중간 산출물(verification.json 등)이 공유 폴더에 함께 남는다. 대량 정리에서는 커밋 기록물이 매우 많아진다(json 원장 수십 개)

## 지시에 넣을 문구
- 금지 파일 목록과 인터페이스 계약(폼 필드·값·응답 형태). 정확한 범위 목록+"지우기 직전 참조 0 재확인", 허용하는 것도 명시
- 설정 변경: "먼저 확인할 사실과 확인 명령, 확인 실패 시 기본 가정"을 단계로 적으면 정확히 따른다. 하지 말 것(실제 -p 실행, 다른 사다리·차단 규칙 변경)을 명시하면 범위를 지킨다
- 대량 파일 이동: 규칙·분류·완료 조건(누락 0·해시 실패 0)·금지(삭제/렌더/GPU)를 표처럼 주면 그대로 지킨다. 2단계(안전 이동 → 승인 뒤 삭제)로 나눠 맡긴다. 진도를 원하면 "사용자가 다른 작업을 멈췄다·삭제 승인됨"을 명시하고, 필요하면 기록물 개수 상한을 적는다
- "요약 맨 앞에 핵심 수치", 앞 위원 상태 파일 경로, "결과가 있으면 재생성 금지", 보고서 양식 원문. 긴 결과는 파일 첫 줄에 결론으로 받는다
- 선행 위원 RESULT.md는 정확한 경로를 적는다. 최종 선택 파일 이름을 RESULT에 적게 한다(중간 산출물과 구분)
- 그림: 표시 칸 실측 크기·비율, 파일 용량 상한, 다양성("N곳마다 다른 형태"), 수치 기준(원본 글자 높이, 층 두께, 색 표본)을 숫자로 적고 의장이 시트를 직접 연다. 결이 중요하면 [gemini-4-argon](models/gemini-4-argon)에 먼저 맡긴다
- 소품 칠하기·합성: "미끄럼 ≤0.5px/f, 불합격이면 제안만", "조각 밖 비트 동일 증명", "Kdenlive는 resource 교체 스크립트만"
- 인물 포함 이미지 편집: 인물별 실제 컷과 설정화를 함께 주고 우선순위를 적는다. 정확한 문구, 바꿀 영역/보존할 영역, 실제 크기와 작은 화면 검수, 원본 보존을 완료 조건에 넣는다
- 미디어 작업: 객관적 미디어 검사(해시·PTS·PSNR)와 청취·인물 유사성 판단을 따로 적는다(청취는 하지 않는다). 제목·문구는 의장이 정식 값을 확인해 준다
- 아이콘 재제작엔 전후·기준 비교 시트를 요구한다(사용자 확인이 빨라진다)
- 캡처는 "실사용 창 크기 그대로", 전용 포트 필수
- "맞는 것은 끝까지 적용, 시안은 지우지 말 것", "전체 테스트 중단 금지(run_in_background)", "재현이 끝내 안 되면 시도한 것만 적고 코드는 바꾸지 않는다"
