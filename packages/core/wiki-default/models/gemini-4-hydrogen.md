Gemini 4 Hydrogen(agy 모델 이름 `gemini-4-hydrogen-{low,medium,high,xhigh}`, [Antigravity CLI(agy)](common/ai-agents/antigravity-agy-cli))의 위원 성향이다. 아직 관찰은 2건(medium: 기존 구조화 문서를 고치고 원본·파생 JSON·검토본을 맞추는 일, 인계 받아 수행 / high: 대사 입맞춤 구절 분할 측정)뿐이라 모델 전반의 확정 성향으로 일반화하지 않는다.

## 잘하는 일
- 범위가 정해진 문서·데이터 수정(medium): 최신 정정이 원 지시보다 우선함, 변경 대상·보존 대상, 재생성 순서, 검증 명령, 스크린샷을 완료 조건으로 분명히 주니 인계 뒤 그대로 수행했다(의장이 diff와 검증 명령으로 다시 확인).
- 범위가 정해진 측정 작업(high): 대사 한 줄을 구절 분할(C1/C2)로 나눠 두 입 열림에 각각 맞추는 작업을 측정 표까지 완성했다.

## 약한 일
- JSON 배열에 항목 1건을 더하면서 파일 전체를 다시 직렬화해 들여쓰기를 바꿔, 불필요하게 큰 diff를 남겼다(병합 충돌 원인).
- 도구 호출이 많다(입맞춤 한 줄 측정에 175회).

## 지시에 넣을 문구
- "최신 정정이 원래 지시보다 우선한다. 원래 완료 조건은 그대로다."
- 원본과 파생물 경로, 바꾸지 않을 데이터(비대상 불변 조건)를 구체적으로 적는다.
- "JSON은 기존 들여쓰기와 줄바꿈을 유지하고 파일 전체 재직렬화를 피한다."
- 측정 작업은 대상 줄·구간과 완료 조건(측정 표)을 정해 범위를 좁혀 준다.
- 완료 검토: 일반 diff와 공백 제외 diff(`git diff -w --stat`)를 둘 다 본다. 성과는 자체 완료 보고가 아니라 따로 다시 검증한 결과로 판단한다.
