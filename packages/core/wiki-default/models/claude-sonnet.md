범위와 절차가 분명한 작업(측정·배포·설치·선례 본뜬 기능 확장·공용 도구 수정·문서·일괄 생성·git 정리·키프레임 재그림·영상 후처리 단건·오디오 패치 통합·삭제 정리)에 안정적이다. 숫자 근거를 내고, 지어내지 않고 멈추는 편이다.
약점은 스스로 검증을 덜 하는 것, 캡처나 실제 처리를 대체물·근사로 바꾸는 것, 비교 입력을 손쉬운 쪽으로 고르는 것, 지시에 적힌 파일만 다루는 것, 지시한 지표만 맞추고 체감을 놓치는 것, 줄 끝 변경이다. 의심스러운 결과는 [claude opus](models/claude-opus)로 검증한다.

## 잘하는 일
### 절차 작업 전반 (low~high)
- CSS·수치·기능+i18n 수정, 읽기 전용 조사, 측정 하네스, 1~2시간 병렬 배치, 라이브 배포·데스크톱 패키징(자산 이름 대조), 사이트 미러+CDP, 저장소 밖 Windows 설정(.lnk). "앞 브랜치 merge → 본 작업"·릴리스 묶음을 번호대로 끝까지 한다
- 숫자 근거(겹침 px·scrollHeight 차)를 대고, 해상도별 하드코딩 대신 일반 규칙을 쓴다. 교란 요인은 NOTES에 적고, 원인이 없으면 추측으로 고치지 않고 보고한다. 의장 전제가 틀리면 근거로 바로잡고, "결과가 숫자까지 같다"는 점에서 하네스의 숨은 버그도 찾는다
- 받은 입력이 지시와 다르면(예: "댄스 분석"인데 춤이 아닌 영상) 사실만 남기고 멈춘다. 실존 인물 프레임은 스스로 커밋하지 않는다. 미충족 조건을 보고 맨 앞에 적고, 재생성 상한을 넘지 않는다. 도구 유무 분기를 그대로 따르고 도구를 가장하거나 주소를 지어내지 않는다
- 측정·밸런스 시안(medium~high): 기존 하네스를 병렬 런처로 감싸 몇 분에 끝낸다. 시안 여러 개를 비교해 목표 범위 한가운데를 고르고, 적용 뒤 시안 raw와 일치를 다시 확인하며, 바뀐 테스트 단정값·문서·번역까지 고친다

### 범위가 좁은 공용 도구 수정·검증 확장·README (medium)
- 공용 스킬의 하위 호환 수정(경로 결정을 새 모듈 하나로 모으고 임시 폴더 픽스처 테스트 추가)을 20여 번의 도구 호출로 끝낸다
- 여러 파일을 관통하는 TS 옵션 추가(zod 도구 스키마 → 내부 입력 타입 → 검사 함수 인자 → 프롬프트 → 테스트)를 정확히 끝낸다. 기존 호출 호환(인자 없으면 기본값)을 지키고 범위 밖은 "가정"으로 보고한다
- TS 다파일 소규모 기능(medium, 6파일 53줄: 이벤트 문구·MCP 도구 인자·git 헬퍼·프롬프트 문구·테스트)을 23 tool call·약 4분에 실수 없이 끝냈다. 지시한 "다른 호출부 grep"을 실제로 하고 기본값 대신 호출부에서 한도를 넘기며, 같은 취지 안내 문구를 지시한 여러 곳 모두 고치고, 경계 테스트(상한·빈 값·없는 경로·잘림·미요청)를 스스로 설계해 더한다. 줄 끝·무관한 리팩터링이 없다
- 실제 CLI 옵션을 `--dry`로 확인한 뒤 문서에 적고, 일부러 파일을 망가뜨려 FAIL이 잡히는지도 확인한다
- 앞 위원의 worktree가 지워져 참고 파일을 못 읽으면 직접 다시 짜고 그 사실을 보고한다

### 원인 조사 (high+advisor opus)
- 캐시/304 문제, 대량 레거시 삭제(기능별 커밋, 옛 저장 호환 테스트)를 실측 숫자·예외 경로까지 다룬다. Dockerfile·pyproject를 로그와 대조해 근거 파일과 함께 원인을 짚는다. "멈출 조건"(비밀번호·docker 없음)에서 정확히 멈추고 사용자 할 일을 문서로 남긴다
- 증거 순서를 주면("ComfyUI /history로 슬롯 배치부터 확인") 가설을 스스로 버리고 소스·같은 시드 비교로 원인을 확정한다
- 전 경로를 추적해 "고칠 게 없다"를 근거와 함께 보고하고, 같은 원인의 다른 화면도 찾아 고친다
- 컷별 표·연속성 점검표·대조 시트 PNG 같은 진단 자료를 잘 만든다
- 판단이 필요한 예외 처리는 [claude haiku](models/claude-haiku) 대신 sonnet에게

### 선례를 본뜬 기능 확장
- "기존 구현/폴더를 본떠라 + 파일 목록·완료 조건·검수 항목"을 주면 프런트+프록시+백엔드 기능 확장, 스토리보드→영상→편집, 저장 소급 지급을 테스트까지 한 번에 한다. 막힌 동작은 테스트로 고정한다
- 선례 커밋을 지정하면(medium, advisor opus) 백엔드·프론트·테스트·캡처를 1커밋에 끝낸다. 선례에 없던 수정 지점도 찾고 가정·미검증·무관한 기존 실패를 밝힌다
- 범위 분명한 서버·웹 기능 연쇄(텔레그램 버튼·토픽·파일 전송 등)는 medium으로 충분, 여러 패키지면 high+advisor opus. 가짜 fetch 테스트를 대량 추가한다
- API 스펙(엔드포인트·필드·SSE 형식)을 주면 Route Handler 프록시+스트리밍 채팅 UI 새 페이지를 한 번에 만든다(medium). 인증 선례가 없으면 백엔드 /auth/me로 풀고 가정으로 보고한다
- 공통 폴더 구조와 CLI·진행 출력 계약을 주면 병렬 모듈이 바로 맞물린다. "실제 도구로 열어 확인"을 주면 Aseprite·Godot 헤드리스·Kdenlive까지 찾아 검증하고, 없는 도구는 미검증으로 적는다
- 대용량 정리는 삭제 전 크기 표와 plan/apply 스크립트를 남기고, 범위 밖은 목록으로만 보고한다

### 구조 설명 다이어그램 GIF·정적 비교 이미지 (Pillow, medium~high)
- 다이어그램 GIF 2건 모두 재배정 없이 한 번에 완주했다(24~28 tool call). 지시대로 커밋을 git show로 읽고 코드와 의장 설명을 대조해, 설명에 없던 사실을 찾아 그림에 반영했다. 코드에서 강제하는 곳을 못 찾은 규칙은 "프롬프트 규칙으로 보고 설명 문구로만 그림"이라고 정직하게 보고한다
- 대표 프레임을 Read로 직접 열어 잔상 글자·중복 글자를 스스로 고친다. 크기 상한(3MB)을 맞추려고 차분 투명 인코딩을 스스로 고안하고, 루프 이음을 "마지막→첫 프레임 변화량이 인접 프레임과 같은 수준"이라는 수치로 검증하며, 박스 글자 폭 자동 검사를 빌드에 넣는다
- 모델 비교 한 장 PNG(카드·막대그래프, medium) 3회(작성 26 call, 수치 교정 4 call, 막대그래프 재설계 6 call) 모두 1회에 완주, 머지 충돌 없음. 선례 스크립트의 폰트 로딩을 본떠 한국어 깨짐이 없고, 줄 수 assert로 칸 넘침을 막으며, .council/shots 사본을 Read로 열어 겹침을 스스로 고친다. 지어내기·다른 파일 수정 금지를 지키고, 수치가 주어지지 않은 기존 값은 '출처 불명'으로 지우고 보고한다. 사용자 원문을 인용하면 일상언어 톤을 정확히 맞춘다([모델·도구 비교 자료 만들기](common/council/model-comparison-images))
- 검증용 임시 파일(.council/verify.py)은 커밋하지 않는다

### 노드·모델 설치·업데이트·라이브 반영 (설치·실측은 high+advisor opus)
- 설치 전에 코드를 점검한다(위험 패턴 grep, install.py 먼저 읽기). pip dry-run으로 기존 패키지 변경 0을 확인하고, 해시 대조로 받는다(Civitai 키가 없으면 같은 작성자 HF 미러의 SHA256·바이트 크기를 Civitai 메타와 대조). 업데이트 전 커밋·pip freeze 기록, 전후 `/object_info` 비교로 충돌 0 증명, 같은 입력 회귀
- 모델 설치→API 내보내기→웹 앱 모드 추가 같은 긴 일을 한 번에 완주한다(sha256·실생성·테스트·빌드)
- 별도 venv(GPU 세대에 맞는 torch), 다운로드 없이 gated HF 상태 확인, 사용자 큐가 빌 때까지 대기. VRAM이 안 맞으면 한 단계 낮은 양자화로 바꾸고 이유를 적는다. 자기 주장이 틀리면 원본으로 확인하고 철회한다
- 라이브 반영(.env 추가·재시작·push)은 단계·확인 명령을 다 주면 medium으로 정확하다. 백업 파일이 gitignore에 안 걸리는 위험을 스스로 exclude로 막는다

### 외부 도구 검토·실측·대량 데이터 (짧은 조사 medium, 설치·실측 비교 high+advisor opus)
- 결과가 이상하면 스스로 대조 실험(2스텝 vs 4스텝)을 추가하고 첫 눈 평가를 수치로 정정한다. high+advisor opus면 ASR 일치율·RTF·VRAM·시드 반복까지 재고 측정 한계(GPU 공유 등)를 적는다
- 외부 라이브러리 vs 자체 도구 벤치: 한 명령(`run.mjs`)으로 재현되는 벤치, 자동 생성 표와 사람이 쓴 해석 분리, "src 수정 금지·외부 저장소 읽기 전용" 준수, 측정 못 한 것·원인 미확인을 따로 적는다
- 대용량 다운로드는 세션과 떼어 받고 sha256 대조. 사라진 입력은 다른 곳에서 찾아 바이트 일치로 증명한다. 결과 원문을 직접 채점해 과장 없이 결론을 낸다("오차 범위라 권하지 않음")
- 원본을 못 받으면 공식 저장소 예제로 대체하고 "원본과 동일 미확인"을 적는다. 출처 불명 미러 금지를 지키고, 큰 파일을 다 못 읽었으면 밝힌다
- 안전: 지시 범위 밖 유해 텍스트는 쓰지 않고 맨 앞에 보고, 삭제는 인용 없이 길이·해시로 확인. 라이선스·콘텐츠 정책 위험은 의장 결정으로 올린다. "연구 전용이면 멈춰라"를 보수적으로 적용하고 HF 접근 동의를 대신 누르지 않는다
- 대량 데이터(이름 1,027개 번역)도 규칙(뜻으로 옮기기, CJK 잔존 0 검사)을 주면 안정적이다(어색한 번역이 몇 % 남는다)
- 실키 검증에서 "키는 env로만, 출력은 앞 5글자"를 지키고 패킷(.council/TASK.md)의 키도 가린다

### 로컬 ComfyUI 일괄 이미지·영상 생성
- 이미지(medium): 워크플로 사본·class_type 패치, /prompt 일괄 제출, 장별 PNG 열람, 크롭 좌표 확인, 불합격 장을 원인별 문구 수정으로 재생성, contact-sheet·prompts.json·RESULT.md 장별 평가까지 정확하다. httpx가 없으면 urllib으로 바꾼다
- 단발 생성·큐 조작: 이전 위원 run.py를 복사해 고치라는 지시를 잘 따른다. "큐를 앞으로" 지시에도 /queue를 먼저 확인해 이미 맨 앞이면 지우지 않는다. 결과가 충분하면 추가 seed를 돌리지 않고 이유를 보고한다
- 영상(high+advisor opus): --prepare-only로 그래프 검증 후 제출, 남의 큐 작업은 기다린다. ffprobe·volumedetect로 프레임·길이·소리를 실측하고 미충족(얼굴 일그러짐·바닥 얼룩·AAC 피크 초과)과 가정을 숨기지 않는다. 실존 인물 파일은 .gitignore
- 수 시간짜리 원격(RunPod) 생성: 포드 2대 분할(claims 파일)·이어받기·구간마다 고정 형식 보고 로그를 유지한다. 노이즈 붕괴를 파일 크기·키프레임 상관으로 잡고 같은 시드 A/B로 우회책을 검증한다. 소리 후처리는 수치·받아쓰기로 검증하고 귀로 못 들은 점을 표시한다
- 웹 Gemini Chrome CDP 생성 반복(새 대화·최대 N회·실패본 보관·시도표)과 Chrome 꺼짐 복구도 성실하다

### 영상 후처리 단건·자막 검증·오디오 패치 통합 (medium~high, 후반 수정은 advisor opus)
- 범위가 분명한 후처리 단건(섬광·히트스톱 제거, ElevenLabs 외침 교체와 입 맞춤, 시트 등록과 cast 반영)을 빠르고 정확하게 한다
- ffmpeg 후처리(업스케일+자막 재번인, medium): 입력·출력 경로, 따라 할 기존 명령 위치(스크립트 행 번호), 수치 완료 조건을 주면 몇 분에 끝내고 오디오 md5·ass cmp·프레임별 PSNR을 보고한다
- 영상 오류 위치 진단(medium): 첨부 시각·컷표·잡·가이드·QC 이력으로 위치를 짚는다
- 자막 교차검증(high): 스템과 마스터의 시간축을 상호상관으로 먼저 확인하고 RMS 쉼·Whisper 단어 순서·기존 앵커를 대조해 잘못 나뉜 문구를 고친다. 경계별 근거·신뢰도를 남기고 "기존 앵커는 독립 근거가 아님", "연속 발화 경계 약 ±0.1초 추정", "직접 청취 안 함"을 구분한다
- 대사 구절 입맞춤(FaceMesh+스템 상관), 마스터 재믹스·프레임 삽입/삭제·덕킹 재계산을 해낸다. 여러 패치 통합에서 "새 옵션을 끄면 이전 마스터와 비트 동일" 게이트를 스스로 세우고, 머지 충돌도 두 기능을 다 살려 푼다
- 정리(삭제) 작업을 게이트 검증까지 끝낸다([중간 산출물 대량 정리](common/git/git-bulk-cleanup-keep-check)). 로컬 영상 부분 재생성(가이드 Codex 합성·노출 보정·시드 측정)도 advisor opus와 함께 안정적이다
- 지시의 "타이틀본 기준"을 그대로 믿지 않고 캡처 대조로 실제 좌표(본편)를 찾아 바로잡는다(그만큼 시간이 든다)

### 키프레임 재그림·투표·음성 후보·구간 설계 위원
- 스토리보드 반영, Codex 재그림, vote-loop 투표(대부분 2회 안에 통과)를 해낸다. advisor opus를 붙이면 안정적이다
- 영상 수정 대량 작업의 설계 위원(sonnet+advisor opus, 병렬): 원인 진단·키프레임·생성기 수정·계획서를 빠르고 꼼꼼하게 한다. "부정문 금지어", "중간 가이드 금지", "생성물 커밋 금지"를 적으면 잘 지킨다
- 지시의 새 파일 이름이 파이프라인과 안 맞으면 스스로 컷 번호 + git mv로 바꾸고 보고한다(맞는 판단)
- ElevenLabs 1테이크 규칙을 지키고, 음높이·음량 수치와 [지금|새] 미리듣기 클립을 만든다

### git 충돌 해결·대량 정리·문서
- 베이스 merge 충돌의 modify/delete를 "실제로 import가 풀리고 돌아가는지"로 판정한다. 계획서 표 기준 대량 git rm(1만 개 규모)도 주석이 근거로 가리키는 작은 md는 남긴다
- git 유지보수(gc·reflog)는 문서의 명령 순서대로 실행하고 사전·사후 점검(worktree·브랜치 수·fsck·남은 ref)을 기록한다. 비가역 단계(prune=now)는 sonnet, 단순 실행은 haiku
- 병렬 테스트 간헐 실패는 재실행·--maxWorkers=1로 구분해 보고한다. 대량 파일 정리(해시 대조로 손실 0), 클릭 누락 재현(실제 마우스)에 꼼꼼하고, 재현 못 하면 "못 했다"고 적는다
- 내용이 정해진 지침 문서·위키 제안(medium, advisor 없이): 규칙 문구를 지시에 다 적어 주면 루트 지침 파일 3개([저장소 규칙 파일](common/council-members/repo-rule-files))를 빠르게 쓰고 동일성을 diff로 확인한다. 관련 위키 수정 제안을 스스로 더하고 밝힌다
- 대형 문서: sonnet(high)+서브에이전트로 넓은 시스템 서술은 되지만 분량 목표의 1.4배로 넘친다. 핵심 확률표는 node 스크립트로 코드 상수와 대조한다. 커밋 기반 개발일지는 medium으로 빠르다(제목 수준 깊이)

## 지시에 넣을 문구
- 공통: 판정 기준·백업 경로·검사 스크립트, 관련 공유 기억 id, 확인할 증거 출처, 보고 언어, 멈출 조건. 출시 작업은 low~medium, advisor opus는 긴 UI·측정에만
- 잘 먹힌 금지: "이름 바꾸지 마라", "서버 실행·종료 금지", "덮어쓰기 전 기존 대상 기록", "줄 끝 변경 금지(Edit 도구)", "이 파일은 다른 위원이 고친다", "md 줄끝 유지(git diff --stat이 바뀐 줄만)", "메인 폴더엔 지시한 파일 외 쓰지 말 것", "기능 코드 변경 금지", "부정문 금지어", "중간 가이드 금지", "생성물 커밋 금지", "남의 작업 삭제·interrupt 금지", "결과는 /history", "원본 수정 금지", "기본값 변경 금지·무관한 리팩터링 금지", "새 파일은 새 폴더에만", 사용자 입력을 바꾸지 말 것. (tmp/ 커밋 금지·.env 출력 금지·전용 포트는 이제 프로그램이 자동으로 한다)
- 범위: 코드 위치·행 번호, 같은 문구가 있는 다른 파일까지, 지킬 것과 지울 것 분리, 목표 수치 범위, 불변 확인 방법
- 코드 수정: 맨 앞에 "목적 한 줄"(문구 변경이면 그 취지), 그다음 "현재 구조: 파일:행 + 함수명" 목록(탐색기 [claude haiku](models/claude-haiku)로 미리 받아 그대로 넣으면 좋다), 할 일을 번호로, 완료 조건에 정확한 명령(예: `npx tsc -b`, `node test/*.mjs`, `npm test` 전체 통과, apps/web `npx tsc --noEmit`)과 "RESULT.md에 마지막 줄·실제 출력 예시". 같은 취지 문구가 여러 곳(프롬프트·도구 설명·이벤트 문구)에 있으면 전부 나열하고 "다른 호출부 grep 확인"을 넣는다. 같은 파일을 건드리는 후속 작업은 앞 작업 머지 뒤 순차 배정
- 공용 도구 경로 변경: "같은 방식으로 옛 경로를 직접 읽는 곳이 더 있는지 grep해서 함께 고친다"
- 넘겨받을 도구가 앞 위원의 것이면 앞 위원이 커밋하게 한다(미커밋 .council/ 파일은 머지 뒤 사라진다)
- 캡처: "실제 모드로 캡처, 정적 페이지 대체 금지"+CDP 스크립트 경로, 캡처 파일명, "네가 띄운 Chrome만 PID로 종료", "수정했으면 build와 캡처를 다시"
- 테스트 명령은 환경 변수(PYTHONUTF8=1)·venv까지 전체 줄로 준다. 안 주면 다른 환경에서 돌려 무관한 실패를 보고한다
- 도구 유무가 불확실하면 "도구 확인 → 없으면 대체물(경로)" 분기. 보고서는 "셸 말고 Write 도구로"
- 완료 조건: 캡처 목록, "첫 줄이 제목인지", "실측 숫자를 RESULT.md에", "측정값 표 필수", "꼭 시도", "RESULT.md에 적은 경로는 Glob으로 존재 확인". 검수에 "물리적으로 말이 되는지"
- 기하·화면 방향 문제: 지표를 체감 기준(예: "화면 이동 각도가 모두 수평 아래 5° 이상")으로 적고, 두 번 막히면 opus로 재배정
- 의심 결과는 opus로 검증. 머지 직후 통합 브랜치에서 `npx tsc --noEmit`를 직접 돌리고, 결론의 방향·짝을 원자료 폴더명·JSON과 대조한다. 줄 끝은 머지 전 `git diff --ignore-cr-at-eol`
- 투명화·자르기 품질 수정이 2회 실패하면 opus로. 생성 지시엔 "시도마다 새 대화, 채택 기준 코드 검사, 실패하면 기존 유지"
- 사용자 표현이 모호한 기능은 지시 전에 데이터로 뜻을 확인한다
- 선례 확장: 선례 커밋 해시("git show로 읽어라"), 건드릴 파일, 하지 말 것, 시험 입력의 조건(예: 정면 그림), 동시 수정 폴더 목록·계약 원문. 외부 서비스가 없는 환경이면 사용자 실행 확인을 따로 남긴다. 노드는 title 대신 그래프 링크로 찾게 한다
