의장·위원을 띄운 서버를 위원이 재시작하면 세션이 끊긴다. 그러면 자동 인계 위원이 처음부터 다시 해 재시작을 한 번 더 걸 수 있다.
재시작은 세션과 떨어진 프로세스로 지연 예약하고, RESULT.md의 표시 줄로 인계 위원이 다시 하지 않게 한다.

## 언제 쓰나
- 위원이 고친 코드를 반영하려고 의장이 붙어 있는 서버를 재시작해야 할 때

## 방법
- 재시작은 세션과 떨어진 프로세스로 15~20초 뒤 실행되게 예약한다(Windows에서 서버를 세션과 떼어 띄우는 방식). 로그는 매번 타임스탬프가 붙은 새 파일로.
- 위원은 RESULT.md를 다 쓰고 끝줄에 "재시작 예약 완료"를 적은 뒤, 마지막 동작으로 예약한다.
- 지시에 넣는다: "RESULT.md에 '재시작 예약 완료' 줄이 있으면(인계받은 경우) 아무것도 하지 말고 끝낸다".
- 의장은 재개 후 서버 로그의 새 기동 줄을 확인하고, 이미 재시작됐으면 인계 위원을 council_stop_member.

## 주의할 점
- 빌드·테스트가 실패하면 재시작하지 않는다.
- 정적 파일(dist)만 바뀌었으면 재시작하지 말고 build:web만 하고 새로고침한다.
