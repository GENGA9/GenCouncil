"결과는 <새 폴더 경로>에" 같은 요청에서는 worktree·머지 흐름이 소용없다. 여러 위원이 같은 외부 폴더에 동시에 쓰고, 의장은 그 폴더를 직접 읽지 못한다.
그래서 폴더 소유를 나누고 출력 계약을 지시에 적는다.

## 언제 쓰나
- 결과물이 git 저장소 밖 새 폴더에 생기는 작업을 여러 위원에게 병렬로 맡길 때

## 방법
- 지시마다 같은 폴더 계약과 CLI·진행 출력 계약(예: `PROGRESS {json}` 한 줄)을 적는다.
- 위원마다 쓸 수 있는 하위 폴더를 겹치지 않게 정하고 적는다: "다른 위원이 X/·Y/를 만든다 — 건드리지 말 것".
- README 같은 공용 문서는 아무도 고치지 않는다. 각자 notes에 "README에 넣을 내용"을 적고, 통합 작업에서 합친다.
- 외부 폴더에서는 git을 쓰지 않는다. worktree에는 RESULT.md만 두고, 확인은 .council/shots의 PNG로 한다.
- 병렬 작업이 끝나면 위원 한 명에게 git init·.gitignore(대용량 제외)·첫 커밋을 맡긴다. 그 뒤로 외부 저장소를 고치는 위원은 한 번에 한 명만 둔다.

## 주의할 점
- 다른 위원이 쓰고 있는 표본을 지우는 정리 작업은 그 작업이 끝난 뒤에 배정한다.
