의장이 요청을 나누고 결과를 보내고 기다리고 검토하는 방법.

## 페이지
- [council-chair-review-tokens](common/council/council-chair-review-tokens) — 위원 결과를 요약+diffstat 먼저, 파일 단위 diff, 큰 결과는 싼 검토 에이전트로(두 번 읽기 낭비 막기)
- [council-chair-waiting-progress](common/council/council-chair-waiting-progress) — 긴 위원 작업 기다리기·진행 알리기(council_wait 대신 이벤트·보고 로그)
- [council-change-running-instruction](common/council/council-change-running-instruction) — 실행 중 위원 지시 바꾸기: 정지 후 재배정
- [council-external-output-folder](common/council/council-external-output-folder) — 결과가 저장소 밖 새 폴더일 때 위원 분장
- [council-external-benchmark](common/council/council-external-benchmark) — 외부 라이브러리 비교 벤치를 공정하게 맡기기
- [council-live-testing-batch](common/council/council-live-testing-batch) — 사용자 실시간 테스트 중 수정 모으기·설계 위원 병렬+생성 묶음 위원
- [council-request-triage](common/council/council-request-triage) — 배정 전 요청·버그 보고 확인
- [council-reverse-docs](common/council/council-reverse-docs) — 역기획서·개발일지를 위원 병렬로
- [council-show-delivery](common/council/council-show-delivery) — council_show로 결과 보내기(허용 형식·소리 후보 mp4)
- [gen-wiki-tools](common/council/gen-wiki-tools) — Gen Wiki 편집·감수 때 도구 동작
- [model-comparison-images](common/council/model-comparison-images) — 사용자에게 보여 줄 모델·도구 비교 자료 만들기
