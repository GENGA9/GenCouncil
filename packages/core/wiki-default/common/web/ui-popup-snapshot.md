상태 변경마다 다시 그리는 UI에서 결과 팝업이 원본 엔티티를 참조하면, 원본이 바뀔 때 팝업도 바뀐다. "HTML이 같으면 생략" 가드로는 못 막는다. 연출이 끝나기 전에 상태를 바꾸면 다른 창에 결과가 미리 보인다.
팝업을 띄우는 순간의 값을 고정하고, 상태 변경은 연출이 끝난 뒤에 한다.

## 언제 쓰나
- 강화·뽑기 결과처럼 연출 후 결과를 보여 주는 팝업을 만들거나 고칠 때

## 방법
- 팝업을 띄우는 순간 표시 대상을 `structuredClone`하고, 표시용 숫자도 문자열로 고정한다.
- 상태 변경은 연출 끝 콜백에서 하고, 그때 대상이 그대로인지 다시 확인한다.
- 창을 닫아 타이머가 취소되면 아무것도 바뀌지 않게 한다.

## 주의할 점
- 테스트: 팝업 → 원본 변경 → render → 팝업 HTML 동일. 가짜 타이머로 연출 중 불변·끝나면 반영·닫으면 취소를 확인한다.
- 다시 그릴 때 크기가 흔들리는 문제는 [UI 크기·버튼 위치가 흔들릴 때](common/web/css-layout-stability).
